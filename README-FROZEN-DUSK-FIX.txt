SOH-EXTREME Frozen Dusk / Ranch Guay fix - 2026-09-29
Version 0.11.32; cumulative Windows x64 Release
Repository: https://github.com/Mikemik444/SOH_EXTREME-Extreme

THE BUG
Your running game configuration uses shuffled Flow of Time and the Dusk preset.
Dusk freezes the clock at 0xB555, before the game's nighttime boundary (>0xC000).
The logic incorrectly treated both Dusk and Night as nighttime. This made the
15 child-night Lon Lon Ranch Guays appear in logic while they could not spawn.

THE FIX
- Dawn, Day and Dusk count as daytime. Only the Night preset starts at night.
- Missing Flow of Time keeps the Guays out of logic at frozen dusk. Obtaining
  Flow allows waiting for night without needing an Ocarina or Sun's Song.
- A true Night start still allows its nighttime checks without Flow of Time.
- Guay Soul, usable combat equipment and child access still apply.
- Shared time helpers, Market wonders and native region reset paths are fixed
  too, so other time-gated checks use the same engine boundary.
- Runtime clock presets, check IDs and receipts are unchanged by this fix.
- All previous cumulative fixes, including the Wolfos/grotto repair, remain
  included. Full history is recorded in SOH_AP_FIX_HISTORY.txt.

WINDOWS DRAG-AND-DROP (NO BUILD NEEDED)
1. Close SOH and Archipelago/Universal Tracker. Keep a copy of the old files.
2. Extract SOH-EXTREME-Frozen-Dusk-Fix-Windows-x64.zip. Replace soh.exe and
   APCpp.dll in the folder you actually launch the game from. Your running
   game was E:\test\bb\x64\Release\soh.exe during this diagnosis; replacing
   only E:\test\bb\soh.exe would not update that copy.
3. Install the included soh_extreme.apworld with Archipelago's Install APWorld
   action. Restart AP/Universal Tracker so it loads 0.11.32.
4. Launch the replaced executable. Use the matching EXE and APWorld together.
Keep game assets, soh.o2r, saves and configuration. Nothing was installed into
your running game, Archipelago installation or saves by this repair task.

SOURCE OVERLAY ALTERNATIVE
1. Extract the CONTENTS of SOH-EXTREME-Frozen-Dusk-Fix-Source-Patch.zip into
   the source root beside build.cmd and CMakeLists.txt; merge/replace files.
2. Open a FRESH Command Prompt in that source root and run build.cmd. Wait for
   the complete build and verification to succeed.
3. Install its matching APWorld and restart AP/Tracker. Launch the rebuilt EXE.
The .patch is for Git/review. Do not apply it again after copying source files.

EXISTING SEEDS
The new tracker rules apply to an existing dusk slot after the update. They
cannot move items already placed using the incorrect rules. Generate new
multiworlds with 0.11.32 for the corrected rules to govern placement. No claim
is made that any particular existing seed remains beatable after correction.
The earlier grotto fix also removed six nonexistent checks from new seeds;
those remain in multiworlds generated by 0.11.30 or earlier.
