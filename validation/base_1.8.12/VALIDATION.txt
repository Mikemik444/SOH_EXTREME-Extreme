SOURCE AND ARCHIVE INTEGRITY
---------------------------
The release finalizer checks every current report's source or archive hashes
against the delivered bytes, verifies previous baseline provenance, retains
all prior validation entries byte for byte, and checks every staged member
against the completed ZIP after writing it. It also verifies the ZIP CRC,
complete source manifest, current APWorld contents, version parity and source
preflight result. The resulting release record is:
  validation/landing_river_1812/landing_river_1812_release_validation.json

REPLAY_INPUTS.json locates each current source, test, dependency and seed-input
hash. The original and previous-release baseline function excerpts are bound
to their verified source hashes. A small river baseline ZIP contains only the
two historical source files needed for that native comparison. REPLAY.txt
explains the focused reruns and required external runtimes.

INTENTIONAL REFILL COVERAGE
--------------------------
Protection turns off only for a verified renewable source of that exact ammo.
Covered sources include retained native shop stock, ordinary unshuffled ammo
scrubs, the Carpet Merchant after the required initial check, audited renewable
overworld enemy placements, and observed fixed-ammo pots/crates with flag zero.
Actual prices, age, path, first-check and physical-use requirements still apply.

Unknown or conflicting container metadata, persistent container drops,
unverified grass/bush sources, unaudited enemy farms and Bowling are not used
to remove protection. They keep the last unit usable. This conservatism avoids
spending the last unit because of an assumed refill. Current zero stays zero.

COMPATIBILITY AND LIMITS
------------------------
Use both the updated native source build and the current APWorld. Existing
seeds retain saved entrance targets and can use the ammo protection. Generate
a new seed to obtain independent Zora's River land and water shuffling.

This partial-source environment cannot produce or launch the user's complete
Windows game build. No Windows executable, controller playthrough or complete
new 1.8.12 item fill is claimed. Native fixtures compile production function
bodies with explicit engine I/O shims and controlled geometry. AddressSanitizer
and UndefinedBehaviorSanitizer are used by the native suites where reported;
LeakSanitizer is disabled because the executor cannot inspect process/task
filesystem information. Real scene collision is evaluated in game at runtime.

Historical evidence from earlier releases is clearly retained under validation.
The previously reconstructed 4,036 placements and 44 progression spheres are
historical seed evidence, not a fresh 1.8.12 full-fill result. The current river
suite replays that saved map and performs a separate new entrance generation.
Use the current APWorld at the ZIP root for installation; older APWorld copies
under validation are historical evidence only.
