LIMITS
-------
A full Windows game build, controller playthrough and complete new 1.8.13 item
fill were not performed here. The focused AP tests
validate real rules/topology with controlled ingress; native fixtures compile
production bodies with explicit engine I/O boundaries. These results do not
prove that an old seed's entire item placement remains beatable after its
age/access rules change. Build the merged complete checkout with the supplied
Windows helper and use both the current native build and matching APWorld.
