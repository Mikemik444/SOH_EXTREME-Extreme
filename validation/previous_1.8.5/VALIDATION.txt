SOH-EXTREME 1.8.5 - Validation evidence and limits
=================================================

Current result: PASS for the checks below. No full native game build or live
gameplay/ImGui verification was performed in this environment.

The authoritative current aggregate is:
  validation/finder_hints_185_release_validation.json
It binds every delivered source file to SHA-256 and verifies the source hashes
recorded by each focused report. SOURCE_FILES.json lists complete replacement
files, sizes, and hashes. This release contains 60 cumulative source files,
including 30 files added or changed since 1.8.4. All prior replacements remain.

1. CHECK FINDER AND NATIVE AP HINT LABELS
   check_finder_descriptive_labels_validation.json
   Compiled C++20 with warnings as errors and UBSan; all 1,493 descriptions
   (421 room doors, 747 enemies, 325 scene/grotto transitions) checked.
   Covers legacy/current names, physical number toggle, age annotations,
   shuffled labels, prefix cleanup, and unknown cross-game hint preservation.
   Shared generator output passes --check. Renderer integration was reviewed;
   the full game/ImGui renderer was not compiled or run.

2. ACTUAL AP LOCATION NAMES AND EXISTING LOGIC
   check_names_185_validation.json
   Official Archipelago 0.6.7; 4,199 canonical names and 4,199 unique numeric IDs.
   1,160 aliases tested independently from the canonical datapackage. Both ages
   constructed 4,044 checks before entrance randomization. All 16 inventory/age
   reachability cases matched the pre-name-change snapshot by numeric ID.
   Parent regions, rule classes, item and region dependencies, and physical
   fields remain identical. Legacy ExcludeLocations, PriorityLocations, and
   StartLocationHints pass AP validation; restored tracker sets normalize too.
   All 421 door identity/cross-dungeon arrival labels were exercised.

3. COMPLETE NATIVE HINT CONTENT
   hints_185_full_content_validation.json
   Twelve compiled cases with ASan/UBSan use the actual hint-data header,
   native client description methods, and shared merchant-name helper.
   A 1,528-byte single hint, 12,231-byte eight-row hint, and 18,357-byte twelve-row
   hint keep all content. UTF-8, literal controls, malformed/oversize snapshots,
   legacy fallback, and merchant text are covered. Session IO is isolated.

4. TEXTBOX FORMATTING AND CONTINUATION
   hints_185_pagination_validation.json
   Thirteen compiled cases plus 200 deterministic mixed-markup fixtures use
   the actual formatter and extracted production normalization/pixel tables.
   ASan/UBSan checks complete text, unbroken names, line width, four-line pages,
   decoded-byte and glyph capacities, UTF-8, operands, color/icon carry, repeat
   formatting, choice alignment, and native EVENT/TEXTID endings.

   hint_page_buffer_validation.json
   Twelve cases and 73,652 assertions run production stream/formatter headers,
   C wrappers, LoadIntoFont, and extracted native open/decode/A/delayed/close
   fragments with minimal engine state. C11/C++20 ABI links, ASan/UBSan, and
   font-buffer canaries pass. 5,000 pages exceeding 65,535 encoded bytes are
   reconstructed exactly. Reopening, language switching, vanilla messages,
   direct buffer replacement, delayed pages, and actor continuations are covered.
   These are scoped native-code fixtures, not a complete-game build.
   Leak sanitizer is disabled because process-task inspection is restricted.
